Aggregate Review

Every tool the workspace has ever run, where it stands against the standard library, and the two decisions needed before the curation pass starts. Branch feat/aggregate, files under docs/aggregate/.

For you to decide

1. Disposition vocabulary

Each of the 209 tools gets exactly one disposition, with a reason:

  • transform — it is, or will be, a standard transform (path).
  • represented-by — an existing transform covers the analysis (e.g. MaxBin2 → the six shipped binners plus DAS Tool).
  • replaced-by — superseded by a different tool (e.g. Prokka → Bakta).
  • dropped — not carried forward (licensed, dead upstream, one-off).

Recommendation: these four, plus a gate-status column (solve / plan / tiny run).

2. Your call on each tool

Mark each row in the census table keep, drop or discuss. Your marks save automatically and Claude reads them back. Keep rows become a transform or a represented-by / replaced-by entry, drop rows are recorded with a reason, and discuss rows come back to you one at a time. Rows you leave unmarked fall back to Claude's call.

Lessons from the first attempt

The E2E install test (engine/install-loop, now engine/rc run 4) never executed a step of its original target in nine-plus rounds. It hit 26 distinct problems, about two-thirds fixed. The largest single cost was a GUI delete that left metabuli in the plan, so setup fetched 205 GB.

  • Size downloads before setup. Metabuli alone is 634 GB packed.
  • Make the harness and watcher right before the first real run.
  • Iterate at the cheapest layer: solve, then plan-only, then setup, then a tiny run. A 3–8 hour cluster setup must not be the unit of iteration.
  • Pin one template and target set; a switch is a new effort.
  • Batch fixes into one release candidate instead of rebuilding per fix.

Coverage beyond the lab

Galaxy

8,276 ToolShed repositories; about 3,300 tools on usegalaxy.eu. galaxy_codex already joins EDAM, bio.tools, bioconda and formats per tool. The 121 IWC workflows are curated and tested, the ground truth KBase narratives were. Wrappers carry real commands, so generated transforms could execute.

Geoquery

Shipped in 0.26.x: 3 transforms, 75 source adapters, verified on 3 AOIs. Its shape (entity table, fan-out per source, aggregate) is domain-neutral. Open: the delivery to Tomer and the DVC push.

ML template

No training transforms on release. Model it on the cyanoverse embedding VAE sweep: split, train, evaluate, collect sweep, with the split kept as its own artifact and a sweep as a fan-out over configs.

Carried from the KBase walk

  • The 493 KBase apps → 54 verbs claim holds: over 99% of narrative use lands on a fitting verb; about 15 apps are misfiled.
  • Five of six random narratives solved to an equivalent plan. The RNA-seq one fails at GO enrichment because nothing produces annotation::gene_set.
  • One unreachable target drops the whole plan without naming which; the planner also substitutes type-valid shortcuts for the tool a story names.
