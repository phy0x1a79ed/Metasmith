Accepted draft, first pass 2026-11-25 (1e ranking folded in; planner guarantees and limits live in 1b):

When an agent writes a pipeline from scratch, each step is an unconstrained guess. Models invent tools and set incompatible parameters (86), and because accuracy on composed tasks falls as steps are added (87), these errors compound over the length of a pipeline. A natural remedy is to restrict the agent to a curated catalogue, so that it can no longer invent what it calls; Biomni, for example, retrieves from 150 tools, 105 software packages and 59 databases (88). A catalogue fixes what can be called, however, not how calls connect, and recent benchmarks locate the remaining failures at exactly these joins. On BioAgent Bench, correct high-level pipeline construction did not guarantee correct steps: agents carried corrupted inputs through to incorrect results without flagging them, and one selected a decoy file because its name matched (89). On FlowBench, failures came from incorrect toolchain selection rather than formatting errors, plans written without a dependency schema came out as edgeless graphs, and models repaired faults by forcing a clean exit while leaving the data invalid (90). Each of these runs to completion and returns plausible output, because nothing checks that one step's output is a valid input to the next. The guarantees of planning close this gap: a stronger model raises the odds that a join is right, but only types make a join checkable, and LLMs cannot reliably verify their own plans. Agents and planners are therefore complementary, as has been argued for planning in general (91): a symbolic solver can generate the valid routes between typed contracts, while an agent turns a question into a target and supplies the heuristics that guide search and rank the valid plans, which matters because redundant tools for the same task disagree widely (37, 92, 93).
