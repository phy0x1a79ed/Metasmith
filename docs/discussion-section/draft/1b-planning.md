If the route were derived rather than written, every module would be reusable at no extra cost to its developer. This would align the incentive of the individual for a faster route to a running pipeline with the incentive of the community for reuse and reproducibility, and is what automated planning promises. A planner accepts a join only when the output type of one tool satisfies the input type of the next, so every plan it returns is valid by construction. Its search is also systematic. The same request returns the same plan, and every join carries a reason that a reviewer can check. APE showed that this kind of planning can compose bioinformatics workflows from annotated tools {Kasalica, 2020 #94}. However, earlier planners could not reach their full potential, and two obstacles held them back. The first was their types. Types that describe what data are let invalid plans through as candidates, and where the vocabulary was fixed, the structure had to be supplied by people instead. For example, Wings specializes templates written by experts rather than composing new workflows {Gil, 2011 #86}. The second was execution, since a plan had no clear path to a protocol that a machine could execute. Metasmith removes both obstacles. Its types carry the state that decides which tools can take the data, so invalid joins never become candidates, and every plan compiles to Nextflow, so it runs as written. Since planning acts before execution, the cases a plan can cover are also limited. Metasmith already finds strong plans, which remain valid under every outcome in the output sets declared by contracts {Cimatti, 2003 #107}. However, conditional planning, which branches on data observed at run time {Peot, 1992 #113}, and strong cyclic planning, which allows for loops such as refining a product until it meets a threshold {Cimatti, 2003 #107}, have yet to be implemented. LLM agents have been applied as an alternative to planners, one that can also execute by composing and running tools directly in Nextflow or a shell. However, they do so without the guarantees that planning provides.
