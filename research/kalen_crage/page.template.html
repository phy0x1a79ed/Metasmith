This is the metasmith plan for answering that, built on the library's isolate genome pipeline. Nothing has been run, and Kalen has not been shown any of it.

What I need from you

1. The assembler. The shipped isolate pipeline names hifiasm‑meta; I used flye instead.

isolate_assembly_from_long_reads targets sequences::hifiasm_meta_assembly, and hifiasm‑meta is a HiFi assembler. These are nanopore reads at median Q23, which is flye's --nano-hq tier, so the plan routes through assembly/flye and the read metadata carries long_read_platform: ont. Say the word if you want the template followed literally instead.

One knock‑on: assembly/select_chromosomal_contigs requires a hifiasm‑meta assembly, so the flye route cannot reach sequences::chromosomal_contig without a change to that transform. The plan does not use it; all three assemblies came back as one circular contig anyway.

2. The nine steps that do not exist yet.

The cargo, comparison and methylation work has no transform in the library, so those steps are stubs: the model is the proposal, the body touches only its outputs. Approving the shape is what lets me write them for real. Three of the nine already have working code behind them in this scope, from the quick pass described at the bottom.

3. The reads are not in the delivery.

The Globus folder holds Plasmidsaurus's own assemblies and annotation, but no FASTQ and no modified‑base BAM. So the plan cannot run as drawn: every lane starts from sequences::long_reads. I have asked Kalen for both. Methylation in particular needs the basecaller's modified‑base tags, which neither plain reads nor an assembly can substitute for.

The DAG

How the plan answers the question

One target was named, crage::report. A metasmith target is a slot the planner has to satisfy consistently with every other slot, so naming each wanted output multiplies the search instead of adding to it; everything the report requires falls out of the plan anyway. Naming all nine returned no plan at all.

Reads to genome

Each colony's reads go through nanoplot and filtlong, then flye, which reads the quality off the QC stats and picks its own preset. prodigal calls genes on the result and diamond_uniref50 and kofamscan annotate them.

The annotation is required to descend from the colony's own assembly. Without that constraint the planner answered it with the parent genome's ORFs, which arrive free with the reference download, and the pipeline would have annotated the wrong genome.

The parent genome

getNcbiAssembly fetches __PARENT__ (__ACC__). It is required under the genome name the accession hangs off, because only the download descends from that. Asking for a bare sequences::isolate_assembly let the planner satisfy the reference by assembling Kalen's own reads a second way, through hifiasm, which would have compared each colony against itself.

The cargo

Each annotated feature of Kalen's plasmid becomes its own record, then is aligned to each colony. Reading features rather than the whole plasmid is what separates an integrated cargo from the delivery backbone, which should not be present at all. cargo_locus merges the hits into one span and reads the colony sequence just outside each end back onto the parent genome, which is what names the junctions. Both recombinase sites with an intact cargo between them is an insertion that went in as intended; backbone still attached, or only one site, is not.

Everything else that changed

reference_diff aligns each colony to the parent and calls the differences, naming each one by the genes it covers, and labelling the cargo span as the insertion rather than counting it as a difference. clone_compare aligns the colonies to each other: colonies picked from one transformation are often siblings rather than independent events, and that changes what a difference in a single colony means.

Methylation

The plasmid carries four methyltransferases, and its annotation names each one's target motif — CTCGAG, CTGCAG, GGCC and ATTAAT. Methylation at those motifs and not elsewhere is what shows the transferred enzymes are working rather than merely present. This arm is blocked until a modified‑base BAM arrives.

One thing already measured

Before your direction arrived I ran a quick comparison by hand on fir, starting from Plasmidsaurus's assemblies rather than from reads. I am holding it back from Kalen, and it needs redoing through this pipeline before it is worth anything, but it says the question is answerable: all three colonies carry the cargo, the colonies are not all independent, and one of them has lost a sizeable stretch of the parent genome. The scripts are in this scope at research/lab/kalen_crage/; two of the proposed steps stand in for them directly.

Its one clear defect is worth naming, because the new step has to avoid it: assembly coordinates are circular, and my script reported two junctions at position zero rather than resolving them the long way round. cargo_locus says so in its own note.
