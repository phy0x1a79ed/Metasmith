The workflow takes two kinds of input per organism: its genome assembly and its RNA reads. Each organism is planned as its own experiment, so EPI300 reads only meet the EPI300 assembly and CB2A reads only meet CB2A. Both follow the same 21 steps.

The workflow

LIB a step metasmith already has, tagged with its library MOCK a stand-in for a step to be written Filled circles are inputs and final outputs; open circles are intermediate files.
Inputs
IN

Genome assembly, RNA reads, sample sheet

One genome assembly (FASTA) per organism, and the R1 and R2 files of each RNA library, grouped under one experiment per organism. The sample_sheet is the one input you would write: which library is which condition.

Prepare the reads
LIB

interleave_zipped_short_reads

Joins each R1/R2 pair into one interleaved file, the form the downstream tools take.

LIB

fastp

Trims adapters and low-quality ends and drops short reads. Writes a per-library HTML and JSON report.

Annotate the assembly
LIB

prodigal

Finds the protein-coding genes in each assembly and writes them as a gene table (GFF) and protein sequences. These are the genes reads are counted on.

LIB

downloadBaktaDB, bakta_noncoding

Finds the rRNA, tRNA and other non-coding RNA genes, which prodigal does not call. Used to measure how much of each library is rRNA.

Map and check
LIB

bowtie2_align

Aligns each library's cleaned reads to its own organism's assembly. Bacterial genes have no introns, so a plain DNA aligner fits.

LIB

samtools_stats

Per-library mapping rate, insert size and error rate.

MOCK

rrna_fraction

The share of reads that land on rRNA and tRNA genes. Bacterial RNA-seq has no poly-A selection, so this says how well rRNA depletion worked and how much depth is left for mRNA.

Count reads per gene
MOCK

featurecounts_strand_sweep

Counts read pairs per gene with featureCounts, three times: unstranded, forward and reverse.

MOCK

pick_strandedness

Keeps the setting that assigns the most reads, which tells us the kit's strandedness without having to ask TCAG.

MOCK

tpm_within_genome

Length-normalised expression (TPM) per gene, for comparing genes within one library.

MOCK

apply_sample_sheet

Relabels the count table's columns with condition and replicate from your sample sheet. The library names alone (epi300_cu1…) do not say which libraries are controls.

Compare conditions
LIB

deseq2

Differential expression between every pair of conditions: fold change and adjusted p-value per gene.

LIB

volcano_plot

Fold change against significance for each comparison, as SVG and PNG.

LIB

expression_clusters

Groups genes that rise and fall together across the libraries (hierarchical clustering).

Metal-resistance genes
LIB

downloadBacmetDB, splitOrfsForAmr, bacmet, merge_bacmet

Searches each genome's proteins against BacMet, the curated database of metal and biocide resistance genes, with DIAMOND.

MOCK

metal_gene_panel

A figure of fold change and TPM for the genes BacMet flags, such as the cus, cop and cue systems in E. coli. Included on the guess that cu means copper; drop it if not.

Report
MOCK

rnaseq_qc_report

One page per organism: trimming, mapping, rRNA share and strandedness for every library, so a weak library is easy to spot before reading the statistics.

Questions for you

  1. What does cu1…cu6 mean? Are these copper exposures (and at which concentrations), time points, independent cultures, or different clones?
  2. Which libraries are the controls, and which are replicates of one another? For example, is EPI300 three control and three treated? A short sheet with library, condition and replicate is all the workflow needs.
  3. Do the EPI300 cultures carry fosmids or plasmids? If so, the assembly should include those sequences, or reads from them will not be counted.
  4. Which assembly should each organism use: one you assembled yourself, or the public RefSeq genomes (EPI300 GCF_052692645.1, CB2A GCF_052446975.1)? If you have your own, where are the FASTA files?
  5. Which comparisons matter most to you? The default compares every pair of conditions.
